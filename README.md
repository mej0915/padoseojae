# 파도서재

노란 물범과 강아지 친구 몽글이가 함께 있는 해변 독서 공간입니다.

- 웹페이지: https://mej0915.github.io/padoseojae/
- 화면 파일: `docs/` (깃허브 페이지가 이 폴더를 보여 줍니다)
- 원본 코드: `src/`, `index.html` · 수정 후 `npm install` → `npm run build:pages` 로 `docs/`를 다시 만듭니다.
- 헤드셋 음악: `src/youtube.js` 의 `YT_DEFAULT` (영상 ID 또는 플레이리스트 ID). 주소 뒤 `?yt=영상ID` 또는 `?ytlist=플레이리스트ID` 로도 바꿀 수 있어요.
- 소리 출처·라이선스: `public/audio/SOURCES.md`
